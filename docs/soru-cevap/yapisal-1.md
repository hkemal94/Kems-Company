# Soru-cevap · Yapısal, 1. set (KKM'nin kendisi)

Kemal'in tıklamalı cevapları, 28 Eylül 2026 gece. Viki için değil;
uygulamanın yapısı, ekranları ve iş sırası için.

## 1. tur — cihaz, menü, ana ekran

| Soru | Cevap |
|---|---|
| Cihaz | **İkisi eşit** (telefon ve bilgisayar) |
| Menü | "Daha küçük, ve yüzdelikler ve sayıları çalışan bir sekme olmalı" |
| Oyun sekmesi | "Bir künye gibi kalsın, açıklama ve özet gibi" |
| Ana ekran | "Daha canlı ve üreten bir ekran" |

## 2. tur — açılımlar

| Soru | Cevap |
|---|---|
| Yüzdeler neyin? | **Künye doluluk, merch, kitap, harita** — "her şey olabilir" |
| Canlı ana ekran | "Yapay zekâ destekli bir içerik ve fikir üretim bölümü istiyorum; onun vitrini ana ekranda olabilir" |
| Oyun künyesi | **Durum, ekran görüntüleri, açıklama ve özet** (depo bağlantısı yok) |
| "Daha küçük" menü | **Daha ince çubuk** (sekme sayısı aynı) |

## 3. tur — yapay zekâ üretim bölümü

| Soru | Cevap |
|---|---|
| Ne üretsin? | **Sosyal medya taslakları, kanon soruları, merch fikirleri** (ad adayları değil) |
| Nereye düşsün? | **"Aday" kutusu**: Kemal onaylamadan kanona / vikiye girmez |
| Kanonu bilsin mi? | **Evet, hepsini** (kanon ve viki bağlam olarak gider) |
| Görsel | **Canva'ya bağlansın**: fikir Canva'da taslak tasarım olarak açılır |

## 4. tur — Merch

| Soru | Cevap |
|---|---|
| En çok gereken | **Kanon kökü, pano görünümü** (Konsept → Tasarım → Üretim → Satışta) |
| Drop sayfası | **İkisi, sekmeyle**: lookbook + çalışma sayfası |
| Stok / satış | **Hayır, başka yerde** |
| Canva | **Her ürüne Canva tasarımı bağlanır** (küçük resim, tıklayınca Canva) |

## 5. tur — Yazı, Galeri, Boşluklar

| Soru | Cevap |
|---|---|
| Yazı bölümü | **Pek kullanmıyor; notlar, taslaklar**; "diğerlerini de isterdim" |
| Kitap ve kanon | **Adlar vikiye bağlansın, tarih uyarısı, yan panel** |
| Galeri | **İkisi**: kayıtlara bağlı görsel arşiv + Canva aynası |
| Boşluklar | **İkisi**: yüzdeler sekmesine ve Neyin Eksik'e katılsın |

## 6. tur — görünüm ve bildirim

| Soru | Cevap |
|---|---|
| Poppins | **Hemen, K paketi** — not: yazı tipi jetonları zaten Poppins (index.css); kalan iş renkler |
| Arayüz renkleri markaya | **Evet**: #1B2A4A → Kolej Laciverti #0E1C4F, #D35057 → #F26B6F (25 dosyada ~380 + ~370 yer) |
| Karanlık mod | **Kullanıyor** — korunacak |
| Bildirim | **"Çok isterim"** |

## 7. tur — bildirim, site, sıra

| Soru | Cevap |
|---|---|
| Hangi bildirimler? | **Haftalık özet, tarihli işler, bekleyen düğme, günün sorusu** |
| Kanal | **Hepsi olabilir** (telefon bildirimi / PWA, e-posta, uygulama içi) |
| Site ve sosyal medya stüdyosu | **Paralel, soru turuyla**: tasarım soruları şimdi, kod sonra |
| İş sırası | **Poppins/renk → Kurucu → ana ekran** |

## 8. tur — yüzdeler ve Yazı

| Soru | Cevap |
|---|---|
| Yüzdeler nerede? | **İkisi**: ana ekranda şerit, ayrıntı kendi sekmesinde |
| Yazıyı ne durduruyor? | **Karışık (Kitap / Blog / Atölye ayrımı), telefonda zor, nereden başlayacağını bilmiyor, vakit yok** |
